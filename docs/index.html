PC Manager

Windows 桌面系统管理工具 —— Flutter 界面 + Rust 核心，经 flutter_rust_bridge v2 无缝集成。监控、清理、工具箱与常驻服务，一个应用全搞定。

快速开始 查看源码

功能特性

从日常监控到深度清理，覆盖桌面管理的主要场景。

实时监控

CPU / 内存 / 磁盘 / 网络仪表盘，健康评分与体检面板，异常即时告警。

进程与启动项

进程列表与结束、启动项启用禁用、开机时长统计。

应用中心

注册表 Uninstall 枚举、应用信息与一键卸载。

深度清理

winapp2 规则引擎、大文件、重复文件（内容指纹）、系统盘分析与回收站。

工具箱

网速测试（延迟 / 抖动 / 上下行）、补丁检测（WUSA / DISM / MSI）。

常驻组件

资源悬浮窗、托盘菜单窗口、采集 Agent（30s 轮询）与 Windows 保活服务。

架构

Flutter 界面经 flutter_rust_bridge v2 直连 Rust 核心；常驻组件以独立进程 + Windows 服务运行。

快速开始

Flutter stable（Windows 桌面）、Rust stable-msvc、VS Build Tools（C++）。

# 克隆并运行
git clone https://github.com/wakawakalululu/computer_manager_rebuild.git
cd computer_manager_rebuild

flutter pub get
flutter run -d windows          # 调试运行
flutter build windows --release # 出包（自动构建 Rust 组件）
